# ProStudio — YouTube Auto Dub

نظام دبلجة تلقائي للفيديوهات من يوتيوب مع دعم متعدد المحركات ونقل البصمة الصوتية.

## الميزات الأساسية

### 🎙️ محرك الدبلجة (TTS)
- **Edge-TTS**: محرك افتراضي سريع وعالي الجودة
- **XTTS-v2**: استنساخ صوت المتحدث الأصلي
- **VoxCPM**: مولّد كلام عصبي مع دعم المرجع الصوتي
- **Qwen3-TTS**: استنساخ متقدم بصوت المتحدّث

### 🔊 تحسين الصوت (Seed-VC)
- نقل البصمة الصوتية للمتحدث الأصلي onto الصوت المولّد
- **40 خطوة انتشار** (diffusion steps) لجودة عالية
- تنظيف المرجع الصوتي: إزالة الضجيج، تطبيع المستوى، تصفية الترددات
- تصحيح المدة تلقائياً مع منع قص الكلمات
- يعمل مع **جميع محركات TTS** وليس محركاً واحداً

### 🎵 فصل المصادر (Demucs)
- فصل عصبي للحوار عن الموسيقى والمؤثرات
- التحقق من صحة الفصل قبل الاستخدام
- إعادة مزج الخلفية اختيارية فقط

### 👥 تعدد المتحدثين
- التعرف التلقائي على المتحدثين (اختياري، يحتاج HF_TOKEN)
- مرجع صوتي مستقل لكل متحدث عند توفر بيانات موثوقة
- وضع محافظ: لا تخمين عند ضعف الثقة

### 📝 الترجمة والصياغة
- ترجمة آلية للحوار
- صياغة إنجليزية حوارية (تحويل "I am" إلى "I'm" إلخ)
- تحضير النص العربي بالتشكيل لتحسين النطق

### 🎬 المزامنة
- محاذاة على مستوى الجملة (لا تعتمد على بداية الجملة التالية)
- منع تمدد الصوت إلى مقطع المتحدث التالي
- `apad` لمنع قص الكلمات في نهاية الجمل
- تصحيح معامل المدة بالـ `atempo` بدلاً من القص

## مراحل المعالجة الكاملة

```
1. التنزيل       → تحميل الفيديو من يوتيوب
2. الفصل         → فصل الحوار عن الموسيقى (Demucs)
3. التفريغ       → تحويل الصوت إلى نص (Whisper)
4. التعرف        → تحديد المتحدثين (اختياري)
5. الترجمة       → ترجمة النص إلى اللغة المستهدفة
6. الصياغة       → تحسين النص ليكون حوارياً
7. التوليد       → تحويل النص إلى صوت (TTS)
8. Seed-VC       → نقل البصمة الصوتية للمتحدث الأصلي
9. المزامنة      → محاذاة الصوت مع توقيت الفيديو
10. المزج        → مزج الموسيقى (اختياري)
11. التصدير      → إخراج الفيديو النهائي
```

## الاستخدام عبر GitHub Actions

1. اذهب إلى **Actions** → **Run YouTube Auto Dub**
2. اختر المهمة: `clone` أو `dub`
3. أدخل الرابط أو مسار الفيديو
4. اختر المحرك واللغة والوضع
5. فعّل الخيارات المطلوبة:
   - `diarize`: التعرف على المتحدثين
   - `separate_sources`: فصل الموسيقى
   - `bg_music`: الاحتفاظ بموسيقى الخلفية

## التحسينات المطبقة

| التحسين | الوصف |
|---|---|
| تنظيف الصوت | إزالة الضجيج قبل إرسال المرجع إلى Seed-VC |
| تطبيع المستوى | تطبيع مستوى الصوت ديناميكياً |
| 40 خطوة انتشار | Seed-VC بـ 40 خطوة لجودة أعلى |
| الحفاظ على الإيقاع | المرجع المنظّف يحافظ على البصمة الزمنية |
| ضبط المدة | تصحيح معامل المدة تلقائياً |
| منع القص | `apad` يحمي نهاية الجمل من القطع |
| صياغة حوارية | تحويل النص الآلي إلى لغة طبيعية |
| وضع محافظ | لا تخمين للمتحدثين بدون بيانات موثوقة |
| suppression | الصوت الأصلي مُزال بالكامل من الناتج |
