# تشغيل الاستنساخ على GitHub

## لماذا على GitHub؟

الاستنساخ يحتاج ملفات نموذج من موقع HuggingFace. الموقع **محجوب** في بيئة
العمل هنا، و**مفتوح** على خوادم GitHub. لذلك يُشغَّل هناك.

جرّبت إطلاقه بنفسي فرفض GitHub الطلب: صلاحيات الرمز الممنوح لي لا تشمل
`workflows` ولا `actions`. الخطوة الأولى وحدها تحتاجك.

---

## الخطوة الوحيدة المطلوبة منك

الملف الجاهز موجود في المستودع باسم `docs/github-actions/dub.yml`.
انسخه إلى `.github/workflows/dub.yml`.

### من المتصفح

1. افتح `docs/github-actions/dub.yml` على GitHub
2. اضغط **Raw** ثم انسخ كل المحتوى
3. اضغط **Add file → Create new file**
4. اكتب في خانة الاسم بالضبط:
   ```
   .github/workflows/dub.yml
   ```
5. الصق المحتوى واضغط **Commit changes**

> تأكد أنك على الفرع `arena/01a03969-prostudio`.

### أو من الطرفية

```bash
git checkout arena/01a03969-prostudio
cp docs/github-actions/dub.yml .github/workflows/dub.yml
git add .github/workflows/dub.yml
git commit -m "enable clone workflow"
git push
```

## ثم شغّله

1. تبويب **Actions**
2. **Run YouTube Auto Dub** من القائمة اليمنى
3. **Run workflow**
4. اختر:
   - **Use workflow from:** `arena/01a03969-prostudio`
   - **task:** `clone`
   - **project:** `Phantom-Thread`
5. اضغط **Run workflow** الأخضر

المدة: **٢٠ إلى ٤٠ دقيقة** (تنزيل النموذج ثم توليد ٢٤ جملة).

## ما تم التحقق منه قبل أن أطلب منك التشغيل

استنسخت الفرع نسخة نظيفة وشغّلت خطوات المهمة عليها فعلياً:

- `requirements.txt` يُثبَّت بلا أخطاء
- السكربتان يُحمَّلان بنجاح
- `build_phantom_dub.py` أخرج **24/24** جملة إلى نفس المسارات التي يرفعها
  الـworkflow

أي أن ما يبقى غير مُختبَر هو تنزيل الأوزان وحده — وهو ما لا يمكن اختباره هنا.

## إن فضّلت جهازك بدل GitHub

أسرع وأبسط، على أي جهاز باتصال حر:

```bash
git clone -b arena/01a03969-prostudio https://github.com/dhiyaddineb-hue/prostudio.git
cd prostudio
pip install -r requirements.txt f5-tts

PROJECT=Phantom-Thread python scripts/clone_project.py
PROJECT=Phantom-Thread python scripts/build_phantom_dub.py
```

النتيجة في `projects/Phantom-Thread/output/`.
