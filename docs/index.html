العمليات

متابعة الدبلجة

حالة كل تشغيل وتقدّم المقاطع تتحدث تلقائياً.

تُحدَّث كل 15 ثانية أثناء وجود تشغيل نشط. التقدم المفصّل يُقرأ من نقاط الاستئناف (checkpoint) لكل مقطع.

الأداء الصوتي

بنك الأصوات والشخصيات

ارفع عيّنات عامة، ثم اربطها بالشخصيات من بطاقة أي فيديو في المكتبة.

إضافة عيّنة صوتية

عيّنة نقية لمتحدث واحد (6–20 ثانية، بلا موسيقى) تُحفَظ في voices/ ويمكن اختيارها لأي شخصية من نافذة «الأصوات» في بطاقة الفيديو. لكل فيديو أيضاً عيّناته الخاصة في library/<الاسم>/voices/.

اتصال GitHub

الصفحة ثابتة على GitHub Pages؛ كل عملية (رفع، حذف، تشغيل، متابعة) تتم مباشرة عبر GitHub API من متصفحك. الرمز يُحفَظ في هذا المتصفح فقط ولا يُرسَل إلى أي جهة سوى api.github.com.

أنشئ رمزاً من هنا (Fine-grained: هذا المستودع فقط، صلاحيات Contents: Read and write وActions: Read and write؛ أو Classic بصلاحية public_repo).
