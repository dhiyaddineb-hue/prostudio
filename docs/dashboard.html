استوديو الدبلجة

ارفع فيديو، اختر اللغات والمحرك وسياسة الصوت، ثم أرسل مهمة آمنة إلى GitHub Actions. هذه الواجهة تستخدم الدبلجة الصوتية فقط؛ لا يوجد خيار مزامنة شفاه مرئية.

إعداد مهمة جديدة

الملف يُرفع إلى فرع ProStudio ثم تُشغّل المهمة من نفس الفرع. حد الرفع المباشر الموصى به 18 MB.

اضغط لاختيار فيديو أو اسحبه هناMP4 · MOV · MKV · WebM — يفضّل أقل من 18 MB
لم يتم اختيار ملف
المزامنة المرئية معطلة عمدًا في هذه الواجهة. الناتج يستخدم مزامنة صوتية زمنية فقط، ولا يمر عبر Wav2Lip أو أي تعديل لبيكسلات الوجه.

الاتصال والتشخيص

أدخل رمز GitHub محدود الصلاحيات للرفع وتشغيل Actions. لا يتم إرساله إلا إلى api.github.com.

اضغط تحديث التشخيص لقراءة حالة المستودع والتشغيلات.
يحتاج الرفع إلى صلاحية كتابة على المستودع، ويحتاج تشغيل Actions إلى صلاحية Actions. لا يمكن للصفحة قراءة Secrets؛ افحص HF_TOKEN وSeed-VC في GitHub Settings → Secrets.

مكتبة الفيديو والمعاينة

تُقرأ ملفات MP4 مباشرة من فرع GitHub. أي فيديو جديد داخل samples أو inbox أو output يظهر بعد تحديث القائمة.
