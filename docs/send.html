أرسل فيديو لدبلجته

اسحب الفيديو في النموذج، اختر اللهجة والأصوات، وأرسل. يُفتح الطلب على GitHub فتصلني إشعاراً به.

افتح نموذج الإرسال ←
يتطلب حساب GitHub (مجاني). النموذج يرفع الفيديو بنفسه — لا تحتاج خدمة تخزين خارجية للملفات حتى ١٠ ميغابايت.

الخطوات

  1. اضغط الزر أعلاه — يفتح نموذجاً على GitHub
  2. اسحب ملف الفيديو وأفلته في خانة «الفيديو»، أو الصق رابطاً
  3. اختر اللهجة والأصوات والإبقاء على الموسيقى من عدمه
  4. الصق النص العربي إن كان جاهزاً — يرفع الدقة كثيراً
  5. اضغط Submit new issue

ماذا يحدث بعدها

١يُستخرج النص من الترجمة الظاهرة على الفيديو، أو يُستخدم نصك
٢يُعزل الحوار الأصلي عن الموسيقى
٣يُعاد الحوار باللهجة المطلوبة بمقاطع متصلة تحفظ التنغيم
٤تُزامن كل جملة على توقيتها ويُمزج الصوت
٥تصلك النتيجة في نفس الطلب، مع صفحة معاينة
