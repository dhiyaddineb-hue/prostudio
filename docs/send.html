الخطوات

  1. اختر ملفك أعلاه
  2. احفظ كل الأجزاء التي تظهر (زر لكل جزء، أو «احفظ الكل»)
  3. اضغط افتح صندوق الرفع واسحبها كلها معاً
  4. انزل لأسفل واضغط Commit changes
هل التقسيم يُخرّب الملف؟ لا. القطع تُقصّ على حدود البايتات وتُلصَق عندي كما هي — بلا إعادة ترميز. الملف المُعاد مطابق للأصل بايتاً ببايت، ومع كل قطعة بصمة SHA‑256 أتحقق منها قبل الجمع، فلو تلف بايت واحد أرفض الملف بدل تسليم دبلجة معطوبة.
لماذا التقسيم أصلاً؟ GitHub يرفض أي ملف فوق 25 م.ب عبر المتصفح («Yowza, that's a big file»). القطع 20 م.ب لكل واحدة، فتمرّ كلها.
