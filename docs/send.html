أرسل ملفك

فيديو أو صوت، أي حجم. اختر الملف ويُرفع مباشرة إلى GitHub — بلا حفظ وبلا إعادة رفع.

  1. افتح صفحة إنشاء الرمز — الصلاحية public_repo مُحدَّدة سلفاً
  2. انزل لأسفل واضغط Generate token
  3. انسخ الرمز والصقه هنا

الرمز لا يُحفظ ولا يُرسَل إلا إلى GitHub نفسه. أغلق الصفحة ويختفي. يمكنك حذفه من إعداداتك متى شئت.

هل هذا يُخرّب الملف؟ لا. الملفات الكبيرة تُقصّ على حدود البايتات وتُلصَق عندي كما هي — بلا إعادة ترميز. مُختبَر: فيديو 74.5 م.ب رُفع وأُعيد جمعه بنفس بصمة SHA‑256 تماماً.
لماذا يلزم رمز؟ نموذج الرفع في GitHub يرفض أي ملف فوق 25 م.ب، وهذه صفحة ساكنة بلا خادم. واجهة GitHub البرمجية تقبل حتى 40 م.ب لكل قطعة، لكنها تحتاج رمزاً — لا سبيل لتجاوز ذلك.
