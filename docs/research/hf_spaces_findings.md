# مراجعة مساري Hugging Face

## Seed-VC
الرابط: https://huggingface.co/spaces/phuoc2005/seed-vc
الصفحة تعرض Space باسم Seed Voice Conversion بواسطة phuoc2005، وحالتها Running on ZERO. واجهة الصفحة الديناميكية لم تعرض تفاصيل API في الاستخراج النصي، لذلك يلزم فحص ملفات Space مباشرة قبل اعتماد أسماء المدخلات.

## VoxCPM Demo
الرابط: https://huggingface.co/spaces/openbmb/VoxCPM-Demo
الصفحة تعرض Space باسم VoxCPM Demo بواسطة openbmb، وحالتها Running. واجهة الصفحة الديناميكية لم تعرض تفاصيل API في الاستخراج النصي، لذلك يلزم فحص ملفات Space مباشرة قبل اعتماد طريقة الاستدعاء.

## ملاحظة
المستخدم طلب الاستفادة من المسارين داخل ProStudio على الفرع الدائم arena/01a03969-prostudio. يجب إبقاء كل مسار اختيارياً وقابلاً للمقارنة، وعدم افتراض واجهة API قبل قراءة كود Space أو README.
